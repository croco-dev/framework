## warning-only 동작 정의
- GitHub Actions step에 `continue-on-error: true`를 설정했다.
- 따라서 위반 발견 시 step 로그에는 madge 실패와 순환 의존 목록이 남는다.
- 하지만 workflow는 즉시 중단되지 않고 이후 `Biome check`, `Build`, `TypeScript check`, `Test`, `Core package coverage gate` 단계로 계속 진행된다.

## 판정
- 위반 발견 시 로그 생성: 확인
- 전체 CI는 계속 흐름: 설정상 확인 (`continue-on-error: true`)
- 로컬 재현 경로 제공: 확인 (`pnpm architecture:check:circular`)
