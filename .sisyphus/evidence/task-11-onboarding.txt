## Onboarding Flow (new contributor path)
1. git clone + cd framework
2. pnpm setup  (single command: install + build + typecheck + test)
3. cp .env.example .env  (only if integrations needed)
4. git checkout -b feat-<description>
5. make changes
6. pnpm check --write  (auto-fix formatting)
7. git push  (pre-push hook runs test + typecheck)
