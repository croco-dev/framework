> **ArtifactType** = `"code"` \| `"types"` \| `"config"` \| `"asset"`

Type of build artifact
- 'code': JavaScript/TypeScript source output
- 'types': TypeScript declaration (.d.ts)
- 'config': Configuration file
- 'asset': Static asset (CSS, HTML, images)
