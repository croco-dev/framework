> **maskEmailAddress**(`email`, `hasPiiPermission`): `string`

Masks an email address when PII read permission is missing.
E.g., user@example.com -> u\*\*\*r@example.com.

## Parameters

### email

`string`

### hasPiiPermission

`boolean`

## Returns

`string`
