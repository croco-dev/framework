Options for an explicit timed-out execution reconciliation pass.

## Properties

### batchSize?

> `optional` **batchSize?**: `number`

Maximum number of records fetched per stable keyset query.

---

### now?

> `optional` **now?**: `Date`

Deadline comparison time. Defaults to the current time.
