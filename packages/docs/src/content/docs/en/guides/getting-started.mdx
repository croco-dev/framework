## Introduction

Croco is an opinionated TypeScript framework optimized for AWS Lambda. It combines HTTP routing, DDD events, transactions, and SaaS metrics under one consistent decorator and type system.

This guide walks you through creating a Lambda-ready REST API in under 5 minutes.

## Install

```bash
pnpm add @croco/transports-http @croco/protocols-rest reflect-metadata
```

## Create Your First Endpoint

```typescript
import 'reflect-metadata';
import { Controller, Get } from '@croco/protocols-rest';
import { createApp } from '@croco/transports-http';

@Controller('/api')
class HealthController {
  @Get('/health')
  health() {
    return { status: 'ok', timestamp: new Date().toISOString() };
  }
}
```

## Create the App

```typescript
const app = createApp({
  controllers: [HealthController],
});
```

## Export Lambda Handler

```typescript
export const handler = app.lambdaHandler();
```

That's it — `handler` is your AWS Lambda entry point. No additional configuration needed.

## Run Locally (Optional)

For local testing without Lambda:

```typescript
await app.listen(3000);
console.log('Server running at http://localhost:3000');
```

Then test with curl:

```bash
curl http://localhost:3000/api/health
```

Expected response:

```json
{
  "status": "ok",
  "timestamp": "2026-01-15T10:30:00.000Z"
}
```
