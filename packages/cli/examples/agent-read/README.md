# Local agent read application

This example reads two local artifacts through `MetricReadService`: a frontend action manifest generated by Croco RPC codegen, and a reviewed report whose payload digest and review provenance are checked against local files. The `frontend.actions.live` query reads the manifest; `frontend.actions` can reuse its matching reviewed report. Both return the same definition, window, quality, revisions, and source location.

From the repository root:

```sh
pnpm --filter @croco/cli... build
pnpm --dir packages/cli exec tsup --config examples/agent-read/tsup.config.mjs
node packages/cli/examples/agent-read/dist/setup.js /tmp/croco-agent-example
export CROCO_AGENT_EXAMPLE_ROOT=/tmp/croco-agent-example
export CROCO_AGENT_APPLICATION="$PWD/packages/cli/examples/agent-read/application.mjs"
node packages/cli/dist/bin/croco-agent.js call listDefinitions '{}'
node packages/cli/dist/bin/croco-agent.js call getVerifiedReport '{"queryId":"frontend.actions","input":{},"window":{"from":"2026-09-01T00:00:00.000Z","to":"2026-09-02T00:00:00.000Z"}}'
node packages/cli/dist/bin/croco-agent.js call runRegisteredQuery '{"queryId":"frontend.actions.live","input":{},"window":{"from":"2026-09-01T00:00:00.000Z","to":"2026-09-02T00:00:00.000Z"}}'
node packages/cli/dist/bin/croco-agent.js call getSourceRef '{"definitionId":"frontend.action-count","sourceRef":"frontend-manifest"}'
```

For MCP, configure the client to run `node` with arguments `packages/cli/dist/bin/croco-agent.js stdio` and pass both absolute-path environment variables above. The published executable is `croco-agent`; its `stdio` and `call` modes use the same application. The module path is selected by the operator at startup. Tool arguments cannot select a module, file, principal, SQL statement, or credential.

The setup bundle uses the repository’s existing tsup tool to resolve codegen’s workspace TypeScript entrypoint. The setup command creates deterministic demonstration data. It initializes a Git repository in the output directory and commits the generated manifest, then records that commit as the source location. Its reviewer and build revision are fixture identities, not claims about a production review. The definition hash is produced by Croco’s metric compiler from the count expression. The fixture assigns the generated actions the timestamp `2026-09-01T00:00:00.000Z`; the executor evaluates that expression against the requested half-open window. The authority grants one fixed local principal access to one aggregate field. Production applications must supply their own authority, registered queries, actual source commit, and trusted review provenance. Keep the application module and provenance directory outside client write access.

Artifact reads reject symbolic links in the resolved directory chain and at the file, require regular files, and stop at the byte limit. The executor uses the effective query budget; the report reader uses the fixed local authority budget. Both observe cancellation between bounded reads. The local report reader verifies the result digest and reviewer provenance. `MetricReadService` owns matching the query version, input, principal, definition, source revisions, snapshots, permission/privacy epochs, window, quality, and budget. An expired report is stale; an altered payload is unavailable; a changed privacy epoch is denied. The CLI returns these outcomes as JSON with exit code 1, and MCP sets `isError`.

`getSourceRef` returns only a registered relative path, commit, and line. No source code or arbitrary file contents are returned. Capabilities explicitly report warehouse, rendering, cache, and trace providers as absent. This example needs no warehouse or external credentials.
