# @croco/seo-core

Public page source contracts and initial HTML inspection. Application repositories own the facts; this package creates no CMS, crawler, sitemap dependency or search ranking score.

A `PublicPageDefinition` names a repository-backed `PublicPageSource`, a production origin, a canonical pathname resolver, meaningful query keys, locale alternates and a supported `Product` or `Article` schema. Published snapshots contain only public facts, revision and modification time. Draft, private, missing, deleted and redirected snapshots carry explicit response policies and no public content. An application must project public fields deliberately; this contract cannot determine whether a repository field is private.

Locale syntax follows the Unicode locale identifiers accepted by `Intl.getCanonicalLocales`, including extension and private-use suffixes. Declared spellings are preserved in metadata; equivalent alternate locales are rejected. Alternates also accept `x-default`. Product facts and marked body offers are inspected only for the `Product` schema; an `Article` projection does not serialize or require them.

`createPublicPageSourceRequest` binds repository reads to the declared production origin, retains only meaningful queries and removes cookies, authorization and bot headers. The renderer and inspector both use it. App callbacks must still project public fields and remain scoped to the registered tenant/site.

`resolvePublicPageMetadata` computes title, description, canonical, language, robots, hreflang and escaped JSON-LD from one snapshot. Product offers use the same source price, currency and availability as the page. Unsupported schemas and invalid facts fail with `seo-core/invalid-public-page`; ratings and reviews are never generated. Canonical paths and redirects cannot contain another origin, a query or fragment. Only explicitly meaningful request queries survive. Alternate paths are on the declared production origin. Preview targets never determine that origin.

`createPublicPageInspector` binds exact target ids to trusted in-process handlers and source definitions. Authorization runs before either source or response access. Callers cannot submit crawl URLs. It reads the actual source and response, parses initial HTML without executing scripts, and compares status, metadata, revision, public description, links and product facts. The source and handler are read separately: concurrent revision changes produce a mismatch for the operator to re-inspect. It never follows redirects or performs network fetches itself. App callbacks remain trusted code and own their own network and tenant boundaries.

`ready` means no declared contract mismatch; `partial` reports validation diagnostics; `denied` means the target is unknown or unauthorized; `unavailable` means the source/response failed or exceeded the five-second/512-KiB inspection bound. Error details and raw HTML are excluded from reports. `formatPublicPageInspection` and JSON consumers use the same `PublicPageInspection`.

The HTML parser uses JavaScript-disabled semantics, including `noscript` content, and excludes scripts, templates and inline-hidden content. Links must preserve their declared destination after applying the first document base URL. External CSS visibility, browser layout and deferred hydration require browser verification. Product renderers mark their visible offer with `data-public-price`, `data-public-currency` and `data-public-availability`. The marked price node displays the exact `currency price` text (for example `USD 37.50`), so a substring or a different visible currency cannot pass. These markers identify the declared facts; the visible availability text must match the source-backed `availabilityLabel`. An inspector is evidence of the declared response contract, not proof of indexing, ranking, deployment certification or arbitrary CSS visibility.

Use `createPublicPageHandler` from `@croco/meta-vite`, `createPublicPageOperations` from `@croco/admin-core`, and `PublicPageInspector` from `@croco/admin-react`. See [the local executable application](../../examples/public-pages/application.mjs).
