Preserve numeric bounds, integer restrictions and array cardinality in contract snapshots and detect incompatible request and response changes. Fresh admin-console scaffolds include their declared numeric constraints in the seeded contract baseline.

Upgrade note: baselines generated by earlier versions omit numeric and array constraints and are compared as unconstrained. Regenerate the baseline from its original schema before assessing newly detected constraints; the old snapshot cannot recover them. Numeric `multipleOf` checks now produce `contract-schema-json-unsafe` diagnostics instead of being silently ignored.
